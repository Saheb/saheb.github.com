Selected Research

Independent work during an ML-focused career break · Aug 2025 – present

False self-correction in Llama-3.1-8B-Instruct

Writeup · Code and experiments

  • Llama rejected correct arithmetic answers for some numbers (e.g. 100, 404) but not others. On 22 cases where it rejected at baseline, three MLP activation edits cut rejection to 3/22.
  • Tested the edits with held-out unit selection and random controls; reverse patches also made selected, previously non-rejecting prompts produce rejection language.
  • Tests of these two numbers suggested different early MLP components and a shared later influence on correctness judgments.

RL fine-tuning OLMo to withhold prohibited exam help

Writeup · Code and experiments

  • Built a custom PyTorch/Transformers/PEFT GRPO trainer for OLMo-3-7B-Think-SFT with LoRA, vLLM rollouts and automated rewards; compared final-answer and whole-completion loss over 12 updates and 864 rollouts per run.
  • Final-answer-only training increased rewarded answer tokens' relative likelihood in 47/51 eligible groups when saved reasoning was provided, yet fresh responses did not clearly improve.
  • Whole-completion loss raised withholding from 68/144 to 81/144 fresh responses to seen prompts. Without policy text, it never refused prohibited help or asked permission (0/24 each on development prompts), so gains remained policy-dependent. One run per loss scope; automated judgments.
